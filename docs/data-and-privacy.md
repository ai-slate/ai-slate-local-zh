# 数据与隐私

本页说明智匣·融智本地版当前的数据流。本软件是本地单机产品：可变运行数据保存在你选择的运行目录；只有在你调用外部模型、在线领取 Licence 或主动提交反馈时，才会产生对应的外部连接。

## 本地保存

全部可变运行数据都位于启动时选择的运行目录（默认 `$HOME/.slate`）：

| 目录 | 用途 |
|---|---|
| `data/current/` | SQLite、缓存、对象和调用内容。 |
| `logs/` | 应用结构化日志与后台进程输出。 |
| `backups/` | 托管的加密备份。 |
| `secrets/` | 当前电脑的登录签名材料等本机秘密。 |
| `generated/` | 启动画像、恢复状态和诊断输出。 |
| `locks/` | 实例锁、维护锁与进程身份。 |
| `tmp/` | 操作级临时文件。 |

数据放在运行目录，而不是安装目录。迁移服务端数据请使用内置备份命令，不要在服务运行时直接复制 SQLite、Pebble 或缓存目录。

## 内容保存开关

管理员可以分别决定是否记录用户内容和服务商原始链路。需要保存的内容先进入队列，再由后台异步写入本机的内容库；这项工作不阻塞调用本身。即使某次内容保存失败，已经产生的用量和费用仍保留在调用记录中。

## 外部连接

以下情形会产生对外连接。请同时检查对应第三方的数据处理、留存和地域规则。

- **模型请求**：完成一次调用所需的请求内容会发送给你在平台中配置的模型服务商。
- **在线 Licence 领取**：支持在线领取的安装包会连接发行方许可证服务；离线环境可以在其他渠道取得与部署 ID 绑定的 Licence 后手动导入。
- **主动反馈**：本地版默认提供“意见反馈”入口。打开反馈面板会为验证码请求发送部署 ID；只有在你主动提交时，才会发送你填写的反馈类型、正文、可选联系方式，以及部署 ID、产品形态和版本。不会自动上传聊天、调用审计、日志或截图。

“本地运行”不等于所有数据永不离机：本地保存的是运行数据，而模型请求、许可领取和主动反馈属于你明确触发的外部连接。

## 诊断包与备份

- **诊断包**：`diagnose` 生成经过脱敏的诊断包；发送前仍应由管理员检查内容。
- **加密备份**：备份文件扩展名为 `.tar.gz.age`，支持 X25519 identity 或交互式口令。identity 相当于备份私钥，丢失后无法恢复，泄露后他人可以解密备份。备份不包含 JWT 签名密钥、日志、锁、Dashboard 或许可证私钥；诊断包、日志、锁和本机登录签名密钥不会作为业务备份恢复到另一台电脑。

## 用户可执行的保护措施

- 管理员密码、调用 API Key、服务商密钥、Licence 私钥和备份 identity 不要写入脚本、聊天记录、日志或诊断包。
- 默认监听 `0.0.0.0` 会允许同一网络中的其他设备访问；只在可信局域网使用，对外提供服务时配置主机防火墙和 TLS 反向代理。
- 首次管理员创建前，仅在可信网络开放服务。
- 建议同时开启 FileVault、BitLocker 或 LUKS 等磁盘加密。
- 把备份文件与 identity 分开保存，并定期执行 `backup verify`。
